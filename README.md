## 📌 About

This is my personal portfolio website, designed and developed from scratch using **HTML and CSS**.

The portfolio presents my background, technical skills, projects, education, achievements, and learning journey while providing a central place to explore my work.

This is the first version of my portfolio and will continue to evolve as I develop new skills and build more advanced projects.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/sushantsolves/My-Portofio-v1.git
```

Navigate into the project:

```bash
cd My-Portofio-v1
```

Open `index.html` in your browser, or use **Live Server** in VS Code for local development.
